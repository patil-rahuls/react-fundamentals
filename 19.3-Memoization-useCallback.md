## Memoization - useCallback()

In JavaScript, functions are objects. 

Every time a component renders, any function declared inside it is recreated as a brand new object in memory with a brand new memory reference.

It is used when passing a function as a prop to a child component wrapped in `memo()`.

&nbsp;

We already know that `memo()` prevents re-renders of the component if props haven't changed. But when passing a function as a prop, the child will see that function definition as a new parameter.

`useCallback()` memoizes a function definition between renders.

> Example: The Problem without useCallback()
>
> ```javascript
> function Parent() {
>   const [count, setCount] = useState(0);
> 
>   // To a child component, this looks like a new prop!
>   const handleDelete = () => { 
>     console.log("Deleted"); 
>   };
> 
>   return <MemoizedChildComponent onDelete={handleDelete} />;
> }
> ```

> The fix - 
> ```javascript
> import { useState, useCallback } from 'react';
> 
> function Parent() {
>   const [count, setCount] = useState(0);
> 
>   // Keeps the exact same reference across renders
>   const handleDelete = useCallback(() => {
>     console.log("Deleted");
>   }, []);
> 
>   return <MemoizedChildComponent onDelete={handleDelete} />;
> }
> ```

&nbsp;

> Another example:
>
> ```javascript
> import RandomNumberComponent from "../RandomNumberComponent";
>
> import { useCallback , useState } from "react";
>
> export const MyApp = () => {
>
>     // Counter
>     const [count, setCount] = useState(0);
>     function handleClick() {
>       setCount(count + 1);
>     }
> 
>     // Random Number
>     const [randNumber, setRandNumber] = useState(null);
>     /* Without useCallback()
>     const handleRandNumber = () => {
>      const newRandNumber = Math.floor(Math.random()*100);
>      setRandNumber(newRandNumber);
>     };
>     The above will be called every time when any change
>     happens in this component. i.e. even if the other state 
>     "count" changes, this function will still get executed.
>     Hence we use 'useCallback' hook along with the dependency
>     array.
>     */
>     
>     /* Correct Solution */
>     const handleRandNumber = useCallback(() => {
>       const newRandNumber = Math.floor(Math.random()*100);
>       setRandNumber(newRandNumber);
>     }, [randNumber]);
> 
>     return (
>       <>
>         <button onClick={handleClick}>
>           Clicked {count} times
>         </button>
>
>         <RandomNumberComponent
>           randomNumber={randNumber}
>           generateRandomNumber={handleRandNumber}
>         />
>       </>
>     );
> };
> ```
